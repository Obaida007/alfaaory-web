# متجر الفاعوري — الواجهة (Next.js)

واجهة متجر **الفاعوري** ([alfaore-store.com](https://alfaore-store.com)) للابتوب والموبايل، مبنية على تصميم «إعادة تصميم متجر الفاعوري». كل البيانات تأتي من الـ API في مشروع [`alfaaory-api`](https://github.com/Obaida007/alfaaory-api).

| المكوّن | التقنية |
|---|---|
| الإطار | Next.js 16 (App Router) · React 19 · TypeScript |
| التنسيق | Tailwind CSS 4 · خط Readex Pro · عربي RTL |
| جلب البيانات | TanStack Query 5 + axios |
| الأنواع | مولَّدة من ملف OpenAPI الخاص بالـ API (`src/types/api.ts`) |

## التشغيل

1. شغّل الـ API أولًا. اتبع README مشروع `alfaaory-api`، وسيعمل على `http://localhost:8000`.
2. ثم:

```bash
npm install
cp .env.example .env.local
npm run dev
```

افتح `http://localhost:3000`.

| المتغير | الوصف |
|---|---|
| `NEXT_PUBLIC_API_URL` | عنوان الـ API، مثل `http://localhost:8000/api/v1` |
| `NEXT_PUBLIC_GOOGLE_CLIENT_ID` | معرّف Google OAuth لزر «المتابعة بحساب Google». إن تُرك فارغًا لا يظهر الزر |

> **CORS:** يجب أن يكون رابط الواجهة ضمن `CORS_ALLOWED_ORIGINS` في ملف `.env` الخاص بالـ API. القيمة الافتراضية تسمح بـ `http://localhost:3000`.

### للإنتاج

```bash
npm run build
npm run start
```

## توليد أنواع الـ API

بعد أي تعديل على الـ API، أعد توليد الأنواع من التوثيق:

```bash
npm run gen:api
```

- **الرابط الافتراضي:** `http://localhost:8000/docs/api.json`.
- **لاستخدام رابط آخر:** مرّره عبر المتغير `API_DOCS_URL`.

## الشاشات

كل شاشة لها نسخة لابتوب ونسخة موبايل. في الموبايل يوجد شريط علوي فيه زر رجوع والرصيد، وشريط سفلي فيه: الرئيسية، الأقسام، الرصيد، طلباتي، حسابي.

| الشاشة | المسار |
|---|---|
| الرئيسية | `/` |
| الأقسام (شريط جانبي + شبكة الألعاب) | `/categories`، `/categories/games` |
| المنتج (أنواع، باقات، إتمام الشراء) | `/categories/pubg-mobile?type=pubg-global-auto` |
| إضافة رصيد | `/add-balance` |
| المحفظة | `/wallet` |
| دفعاتي | `/deposits` |
| طلباتي | `/orders` |
| المفضلة | `/favorites` |
| الإشعارات | `/notifications` |
| حسابي | `/account` |
| تسجيل الدخول | `/login` |
| إنشاء حساب | `/register` |
| استعادة كلمة السر | `/forgot-password`، `/reset-password` |
| من نحن | `/about` |
| سياسة الخصوصية | `/privacy` |
| البحث | `/search?q=` |

### مسار `/categories/[slug]`

مسار واحد يعرض الشجرة كلها، والعرض يتغيّر حسب مستوى القسم:

- **قسم رئيسي** (مثل قسم الألعاب): شبكة ألعابه.
- **لعبة** (مثل PUBG MOBILE): صفحة المنتج، وأنواع اللعبة تظهر كتبويبات.
- **نوع** (مثل PUBG GLOBAL AUTO): يحوّل إلى صفحة اللعبة مع اختيار هذا النوع.

## ملاحظات

### تسجيل الدخول
- توكن Sanctum يُحفظ في `localStorage`.
- الصفحات الخاصة تحوّل الزائر إلى `/login?next=…`.
- إذا كان التحقق بخطوتين مفعّلًا، تطلب الصفحة الرمز المرسل إلى البريد.

### الشراء
- لكل باقة مختارة `Idempotency-Key` جديد.
- إعادة إرسال الطلب نفسه (مثلًا عند انقطاع الشبكة) لا تخصم الرصيد مرتين.
- بعد الشراء تنتقل الصفحة إلى `/orders?placed=1`، وتظهر رسالة «تم استلام طلبك».

### الصور
- كل قسم أو لعبة له صورة يرفعها المشرف من لوحة التحكم.
- إن لم تُرفع صورة، يظهر بديل كما في التصميم:
  - الأقسام الـ 11: رسومات SVG مرسومة لكل قسم.
  - الألعاب: مربع فيه أول حرفين من الاسم، مثل `PU` لـ PUBG MOBILE.

### سياسة الخصوصية
- تُكتب من لوحة التحكم ← الإعدادات.
- سطر يبدأ بـ `## ` يصبح عنوان قسم، وسطر يبدأ بـ `- ` يصبح نقطة في القائمة.
